# Florin app decisions deck

The Claude Slides deck at https://claude.ai/artifact/2h5ikADR2eFCY1DZYbJEJU. `project/` is exactly what is published
(deck.json and one file per slide); `embeds/` holds each slide's live x-embed as a standalone page for testing.
DECK-FORMAT.md is the slide format. Publish with the Artifact tool: `url` the deck, `root` this folder, deck.json first.
Figures are computed from the prototype model (FLD.build for the demo people) and written in by hand.
